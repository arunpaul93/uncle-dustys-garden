# Project hosting

- Keep this project in the local checkout and GitHub only, as requested by the user.
- Use GitHub Pages for hosting at uncledustys.com.au.
- Use `master` as the default branch and GitHub Pages deployment branch; merge work into `master`.
- Publish the static `dist/` directory through `.github/workflows/pages.yml`.
- Do not create, reconnect, or publish a ChatGPT Site, or add Sites hosting configuration.
- Preserve the GoDaddy email DNS records when changing website hosting.
